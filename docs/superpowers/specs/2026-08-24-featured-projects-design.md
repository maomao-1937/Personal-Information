# 精选项目更新设计

## 目标

更新个人主页的「精选项目」栏目，使其展示 7 个项目，并让其中 6 个项目可以跳转到对应的 GitHub 项目目录。

## 内容范围

- 保留现有「爱支招」卡片及其当前文案、标签和技术栈；由于没有提供链接，该卡片保持不可点击。
- 移除现有旧版 ExplainBack 卡片。
- 按以下顺序加入 6 个项目：
  1. AI Conversation Quality Inspector
  2. ExplainBack
  3. Learning Supervision and Planning Assistant
  4. MeetingMemo
  5. ShipCheck
  6. 灵感星图
- 新项目的标题、描述和 GitHub 地址严格采用用户提供的内容，不补充未经确认的技术栈信息。
- README 中的精选项目说明同步更新为当前项目列表。

## 交互设计

- 带链接的 6 张卡片整体作为链接，在新标签页打开。
- 带链接的卡片底部显示明确的「去查看 →」操作文案，替代只有符号的箭头。
- 外部链接设置 `rel="noopener noreferrer"`。
- 卡片保留现有悬浮动效，并增加清晰的键盘焦点样式。
- 「爱支招」继续使用非链接卡片样式，不制造无效跳转。

## 实现边界

- 继续使用 `window.SITE.projects` 作为唯一项目数据源。
- 项目渲染根据 `url` 是否存在，分别输出链接卡片或普通卡片。
- 不调整栏目布局、全站配色、导航和其他个人信息。
- 不新增框架或运行时依赖。

## 验收标准

1. 页面最终渲染 7 张项目卡片，「爱支招」仍为第 1 项。
2. 页面只出现 1 个 ExplainBack，且使用新的描述和链接。
3. 其余 5 个新项目的标题、描述和链接均与用户提供内容一致。
4. 6 个 GitHub 项目可通过整张卡片打开，且使用新标签页及安全的 `rel` 属性。
5. 6 个 GitHub 项目均显示「去查看 →」，「爱支招」不显示该文案且不产生跳转。
6. 桌面端保持两列布局，窄屏保持单列布局。
7. 现有测试、静态检查或构建流程（如项目中存在）继续通过。
